# Memory Game: Mauryan Administration

This is a simple, browser-based memory game designed for students preparing for competitive exams like UPPCS.

## Features
- **Stage 1:** Entry screen.
- **Stage 2:** 2-minute memorization timer with key historical data.
- **Stage 3:** Interactive fill-in-the-blanks quiz.
- **Stage 4:** Automated scoring and feedback.

## How to use:
1. Upload `index.html` to a GitHub repository.
2. Go to **Settings > Pages**.
3. Select the `main` branch and `/root` folder.
4. Your game will be live at `https://<your-username>.github.io/<repo-name>/`.
